# ChronoShot
Открытый и свободный аналог прошивки для хронографов серии «Хронолайт» / «Жидкий хронолайт» с поддержкой ЖК-экранов. Проект создан как альтернатива закрытым коммерческим решениям для тех, кто хочет свободно модифицировать код, менять пины, настраивать датчики и адаптировать устройство под свои задачи без ограничений со стороны автора оригинала.
