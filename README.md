# Измеритель скорости пульки (PIC16F676)

Устройство предназначено для измерения скорости полета объектов (например, пульки) между двумя датчиками с помощью микроконтроллера PIC16F676 и вывода результатов на символьный LCD-дисплей 0802.

---

## 🎯 Диапазон и возможности измерений

* **Измерение скорости:** Позволяет фиксировать скорость летящих объектов (включая стрельбу из пневматики, страйкбольного оружия или даже замер скорости брошенной вручную пульки/предмета).
* **Диапазон скоростей:** Уверенно измеряет значения в диапазоне **от малых скоростей (порядка единиц м/с, например, от 1–5 м/с для брошенных вручную объектов) до высоких скоростей (сотни м/с)**, ограниченных лишь быстродействием датчиков и разрядностью таймера.

Данный проект является **полностью открытой и свободной альтернативой** для тех, кто столкнулся с закрытым исходным кодом популярных  хронографов (таких как «Хронолайт» а точнее его модификации с ЖК-экранами).

* **Для кого это:** Этот репозиторий создан для радиолюбителей, страйкболистов и разработчиков, которым надоели закрытые ограничения. Берите прозрачный код на C, дорабатывайте под любые кастомные корпуса, датчики и наслаждайтесь свободой творчества!

## ⚙️ Основные характеристики

* **Микроконтроллер:** PIC16F676.
* **Тактовая частота:** 20 МГц (внешний высокоскоростной кварцевый резонатор HS).
* **Дисплей:** Символьный LCD 0802 (2 строки по 8 символов), подключенный в 4-битном режиме.
* **Датчики:** Подключены к выводам порта A (RA1 — старт, RA0 — стоп).
* **Точность таймера:** Таймер TMR1 с тактированием от машинного цикла (1 тик = 0.2 мкс при кварце 20 МГц).

## 📏 Изменение длины базы (`BASE_LENGTH_MM`)

Параметр `BASE_LENGTH_MM` задает физическое расстояние между датчиками (старт и стоп) в миллиметрах. По умолчанию установлено **100 мм** (10 см):

```c
#define BASE_LENGTH_MM 100 
```

### Как изменить длину базы:
1. Измените значение макроса `#define BASE_LENGTH_MM` на ваше реальное расстояние в миллиметрах (например, для 15 см укажите `150`).
2. Выполните перекомпиляцию проекта.
3. **Внимание:** Изменение физического расположения датчиков на макете без обновления этого значения в коде приведет к неверному расчету скорости.

## 🧮 Расчет скорости и формулы

### 1. Константа скорости (`SPEED_CONST`):
Рассчитывается автоматически на этапе компиляции:
$$\text{SPEED\_CONST} = \text{BASE\_LENGTH\_MM} \times 500000UL$$

*Число `500000UL` учитывает частоту машинных циклов процессора (5 МГц) и перевод единиц таймера в секунды с масштабированием под миллиметры.* Для базы 100 мм константа равна `50 000 000`.

### 2. Итоговая формула скорости:
Когда объект пересекает оба датчика, таймер фиксирует количество тиков (`ticks`). Скорость вычисляется по формуле:
$$\text{Скорость (м/с)} = \frac{\text{BASE\_LENGTH\_MM} \times 500000}{\text{ticks}}$$

* **Пример:** При базе 100 мм и значении таймера `ticks = 250 000` тиков:
  $$\text{Скорость} = \frac{50 000 000}{250 000} = 200 \text{ м/с}$$
  На дисплей выведется значение `V=200,0`.

## 📌 Ошибки и индикация на дисплее

* **Успешный замер:** На нижней строке отображается рассчитанная скорость (`V=XXX,XX`), на верхней — счетчик выстрелов (`00...99`) и состояние датчиков.
* **Ошибка (`Err`):** Если первый датчик пропущен, произошло зависание (таймаут переполнений таймера) или зафиксирован недопустимый интервал, на экране отобразится статус `Err` и стрелочки (`>`), указывающие, какие именно датчики подавали признаки активности.
