# Измеритель скорости (PIC16F676)

Устройство предназначено для измерения скорости полета объектов (например, пульки) между двумя датчиками с помощью микроконтроллера PIC16F676 и вывода результатов на символьный LCD-дисплей 0802.

---

## 🛠️ Среда разработки и компилятор

* **Компилятор:** Microchip XC8 **версии 1.33**.
* **Режим сборки:** Для успешной компиляции и укладывания кода в жесткие лимиты памяти микроконтроллера PIC16F676 настоятельно рекомендуется использовать компилятор **в режиме PRO** (или с активированными максимальными оптимизациями), так как стандартный режим может приводить к избыточному размеру бинарного файла.
* **Особенности:** В коде подавляется предупреждение `Warning 752` (`#pragma warning disable 752`) для корректной работы со сдвигами 16-битных переменных.

---

## 🎯 Диапазон и возможности измерений

* **Измерение скорости:** Позволяет фиксировать скорость летящих объектов (включая стрельбу из пневматики или страйкбольного оружия).
* **Пограничные значения измеряемых скоростей (Аппаратные лимиты):**
  * **Верхний предел (Ошибка `Err_Hig`):** Срабатывает, если время пролета пули меньше **1.5 мс** (`t_main_raw < 1500` тиков). Для базы 100 мм это соответствует скоростям **выше ~333.3 м/с**.
  * **Нижний предел (Ошибка `Err_Lou`):** Срабатывает, если время пролета превышает **12.9 мс** (`t_main_raw > 64500` тиков). Для базы 100 мм это соответствует скоростям **ниже ~7.75 м/с**.
  * **Таймаут/Застревание (Ошибка `Err_IN`):** Срабатывает при аппаратном переполнении таймера TMR1 (если пуля не долетела до второго датчика за 13.11 мс).
  * **Нарушение порядка (Ошибка `Err_OUT`):** Срабатывает, если второй датчик сработал раньше первого.
* **Энергонезависимый архив:** Автоматическое сохранение до 63 последних измерений в EEPROM микроконтроллера с возможностью навигации и просмотра.

## 📏 Длина базы и рекомендации по ее изменению

Базовая длина по умолчанию в текущей прошивке физическое расстояние между датчиками составляет **100 мм (10 см)**. Ей соответствует следующая константа:

```c
#define SPEED_CONST 50000000UL
```

**Рекомендации по изменению кода, если база отличается:**

Если вы изменили расстояние между датчиками в вашем физическом устройстве (например, сделали базу 150 мм или 200 мм), вам необходимо пересчитать и изменить макрос `SPEED_CONST`.

**Формула для расчета константы:**
```
SPEED_CONST = Длина базы в мм * 500000UL
```

**Пример для базы 150 мм:** `150 * 500000UL = 75000000UL`. Замените значение в строке кода:
```c
#define SPEED_CONST 75000000UL
```

После изменения константы обязательно выполните перекомпиляцию проекта. Изменение геометрии датчиков без правки `SPEED_CONST` приведет к математической погрешности в расчете скорости.

## ⚙️ Основные характеристики железа

* **Микроконтроллер:** PIC16F676.
* **Тактовая частота:** 20 МГц (внешний высокоскоростной кварцевый резонатор HS).
* **Дисплей:** Символьный LCD 0802 (2 строки по 8 символов), подключенный в 4-битном режиме через программный теневой регистр (`shadow_portc`) для защиты от RMW-ошибок.
* **Датчики:** Подключены к выводам порта A (RA1 — старт, RA0 — стоп) с использованием внутренних подтягивающих резисторов.
* **Точность таймера:** Таймер TMR1 с тактированием от машинного цикла без предделителя (1 тик = 0.2 мкс при кварце 20 МГц).

| Вывод МК (PIC16F676) | Назначение / Периферия | Описание подключения |
|----------------------|------------------------|----------------------|
| RA0 / AN0 | Датчик 2 (Стоп) | Подключение стопового датчика (активный уровень — ноль при перекрытии) |

## 🧮 Формула расчета скорости

Когда объект пересекает оба датчика, таймер фиксирует количество тиков (`t_main_raw`). Скорость вычисляется по формуле:

```
Скорость (м/с) = SPEED_CONST / t_main_raw
```

Где:
- `SPEED_CONST` = 50,000,000 (для базы 100 мм)
- `t_main_raw` = количество тиков таймера (1 тик = 0.2 мкс при 20 МГц кварце)

---

## 🎮 Управление и функции кнопок

* **Просмотр архива:** Нажатие кнопок «Плюс» или «Минус» переводит устройство в режим просмотра ранее сохраненных значений из EEPROM.
* **Очистка памяти:** Одновременное удержание обеих кнопок («Плюс» и «Минус») в течение 2 секунд полностью очищает архив выстрелов в EEPROM и сбрасывает счетчик на ноль.

---

## 📊 Формат отображения на дисплее

**Первая строка:**
```
XX  -  -
```
Где:
- `XX` - номер выстрела (от 01 до 63)
- Первый `-` или `X` - состояние стартового датчика (`-` = свободен, `X` = перекрыт)
- Второй `-` или `X` - состояние стопового датчика (`-` = свободен, `X` = перекрыт)

**Вторая строка:**
```
V=xxx,yz
```
Где:
- `V=` - префикс скорости
- `xxx` - целая часть скорости (0-999 м/с)
- `yz` - дробная часть скорости (сотые доли м/с)

**Режим ошибки:**
```
Err_XXXX
```
Где `XXXX` - тип ошибки: `IN  `, `OUT `, `Low `, `Hig `

## ⚡ Программные особенности

### Защита от RMW-ошибок
Используется теневой регистр `shadow_portc` для управления пинами дисплея, что предотвращает ошибки типа "Read-Modify-Write" при работе с портами PIC-контроллеров.

### Слепое окно
Программная защита от срабатывания датчиков на пороховые газы - после измерения скорости активируется 1-секундная блокировка входов.

### Автоматическое сохранение
Каждое измерение автоматически сохраняется в EEPROM с циклической перезаписью (63 последних измерения).

### Проверка ошибок
Комплексная система валидации измерений с защитой от аппаратных сбоев, некорректной последовательности срабатывания датчиков и физически невозможных скоростей.

---

## ⚠️ Важные замечания

1. Для корректной работы необходим внешний кварцевый резонатор 20 МГц
2. Кнопки должны быть подключены с подтяжкой к питанию (внутренние подтяжки активированы в коде)
3. Оптические датчики должны выдавать активный низкий уровень при перекрытии
4. LCD дисплей должен быть типа 0802 с контроллером HD44780
5. При изменении длины базы обязательно пересчитайте константу `SPEED_CONST`
